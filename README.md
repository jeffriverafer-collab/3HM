# 3HM CHEMICAL

Réplica visual educativa inspirada en la estructura pública de una web de productos para acabados.

## Estructura

- index.html
- css/style.css
- js/script.js
- img/

## Ejecutar

Abre `index.html` directamente en el navegador.

## Imágenes

Las áreas visuales incluidas en esta versión utilizan fondos CSS para que el proyecto funcione sin depender de archivos externos. Puedes reemplazarlas por fotografías propias dentro de `img/`.

## Nota

Este proyecto no contiene una copia del código propietario, logotipo oficial ni fotografías protegidas de terceros. Es una implementación independiente de la estructura y experiencia general.
